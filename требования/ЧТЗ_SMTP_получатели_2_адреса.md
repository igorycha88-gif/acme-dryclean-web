# ЧТЗ: Получатели заявок — 2 адреса Яндекса

**Дата:** 2026-09-22
**Статус:** УТВЕРЖДЕНО (малая задача)
**Маршрутизация:** Аналитик → Разработчик → Тестировщик → DevOps

## 1. Задача
Заявки с сайта должны приходить на **два** ящика:
`Alenka200893@yandex.ru` и `igorycha.s@yandex.ru`.
Текущий получатель по умолчанию (`da-drycleaning@yandex.ru`) заменяется.

## 2. Решение
- nodemailer поддерживает несколько получателей в `to` через запятую —
  **изменения кода отправки не требуются**, правится только конфиг.
- `SMTP_USER` (ящик-отправитель, пароль приложения) остаётся прежним.

## 3. Файлы
| Файл | Действие |
|---|---|
| `.env.example` | `SMTP_TO=Alenka200893@yandex.ru,igorycha.s@yandex.ru` |
| `docker-compose.dev.yml` | default `SMTP_TO` → те же 2 адреса |
| `frontend/src/app/api/orders/route.test.ts` | + тест: 2 получателя пробрасываются в `sendMail` |

## 4. Критерии приёмки
- **AC-1:** при настроенном SMTP письмо уходит на ОБА адреса (проверка в тесте: `to` = оба адреса).
- **AC-2:** `npm test`, `npm run lint`, `npx tsc --noEmit` — зелёные.
- **AC-3:** деплой — полная пересборка, все сервисы healthy.

## 5. Не входит в объём
Изменение кода отправки, добавление копий (CC), валидация адресов получателей.
