## 1. Постановка задачи

Для добавления сайта в Google Search Console требуется подтвердить право владения сайтом методом «HTML-файл»: файл `google0f696e1033e85b54.html` должен быть доступен по адресу `https://<домен>/google0f696e1033e85b54.html` и содержать ровно одну строку:

```
google-site-verification: google0f696e1033e85b54.html
```
