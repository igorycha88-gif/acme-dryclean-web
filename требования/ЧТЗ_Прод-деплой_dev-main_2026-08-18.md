# ЧТЗ — Слияние dev → main и продакшн-деплой (Blue-Green)

**Дата:** 2026-08-18
**Маршрут:** Маршрут 5 (Продакшн-деплой): PROD-ANALYSIS → Тестировщик (Quality Gate) → DevOps
**Исполнитель:** DevOps (слияние + деплой через GitHub Actions deploy.yml)

## 1. Бизнес-задача

Выпустить на продакшн (https://da-dryclean.ru, VPS 37.143.15.148) накопленные
изменения из ветки `dev` (12 коммитов), выполнив слияние в `main` и запуск
blue-green деплоя через CI/CD.

## 2. Состав изменений (dev опережает main на 12 коммитов)

### Функциональные (frontend/SEO):
- **Review Schema fix** (18c7fe9): отзывы вложены в LocalBusiness JSON-LD —
  исправление ошибок Google Rich Results
- **Кнопка отзывов Яндекс.Карты** (252d370) + редирект ссылки отзывов на
  Яндекс.Карты вместо 404 /otzyvy (f890ae9)
- **robots.txt** оптимизация под краулеры Яндекса (f19fb79)
- **Прайс-лист PDF** — скачивание вместо inline-просмотра (6bab870)

### Функциональные (backend/мониторинг):
- **Бизнес-метрики** (d569b53): content-service /metrics (prometheus_client,
  HTTP counters/histograms), tracking-service business_metrics_loop
  (business_* гейджи каждые 60с)
- Модели tracking переведены на SQLAlchemy 2.0 typed style — **без изменения
  схемы БД** (колонки идентичны, миграций нет)

### Инфраструктура/безопасность:
- **Security** (dd8605b + фиксы): все Docker-порты привязаны к 127.0.0.1,
  Grafana за nginx basic-auth (/grafana/, htpasswd), UFW отключён (риск
  блокировки SSH)
- **Экспорт метрик** для центрального мониторинга: /metrics/{tracking,content,
  node,postgres} через nginx :443 с X-Monitoring-Key + rate limit
- postgres-exporter в docker-compose.prod.yml (127.0.0.1:9187)
- Healthcheck фиксы (--spider) в docker-compose.dev.yml

## 4. Критерии приёмки

1. AC-1: dev слит в main без конфликтов, main запушен в origin
2. AC-2: CI (lint/typecheck/tests) зелёный на main
3. AC-3: deploy.yml (workflow_dispatch) выполнен успешно: build → push GHCR → blue-green на VPS
4. AC-4: Smoke-тесты прошли (content/frontend/tracking/prometheus/grafana — 200)
5. AC-5: https://da-dryclean.ru отдаёт 200, работает сайт
6. AC-6: Авто-откат НЕ сработал (деплой успешен)

## 5. План отката

- Автоматический: deploy-vps.sh auto-rollback при FAIL smoke-тестов
- Ручной: `./scripts/rollback.sh` или повторный деплой предыдущего образа
- БД: бэкап создаётся перед деплоем (Step 2, pg_dump + gzip)
