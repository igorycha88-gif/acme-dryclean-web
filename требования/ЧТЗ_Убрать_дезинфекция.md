# ЧТЗ: Убрать слово «Дезинфекция» из описаний услуг

**Дата:** 2026-08-28
**Маршрут:** 1 (Стандартная: Аналитик → Разработчик → Тестировщик → DevOps)
**Исполнитель:** Разработчик (frontend)
**Тип:** Контентная правка (текст)

## 1. Контекст и мотивация

Услуга «дезинфекция» требует разрешительных документов (СЭС-лицензия/санитарно-эпидемиологическое заключение). Компания D&A Dry Cleaning не оказывает дезинфекцию как самостоятельную услугу и не имеет соответствующих документов. Упоминание слова «дезинфекция» в описаниях услуг создаёт юридические риски (вводит клиента в заблуждение относительно состава услуги).

## 2. Цель

Полностью удалить слово «дезинфекция» (во всех падежах и формах: «дезинфекция», «дезинфекцию», «дезинфекции») из всех описаний услуг, SEO-полей, преимуществ, статей блога и страниц сайта, где речь идёт о:
- химчистке матрасов;
- химчистке ростовых кукол;
- химчистке ковролина.

## 3. Затронутые файлы (5 файлов, frontend)

1. `frontend/src/lib/serviceData.ts` — описания услуг (матрасы, ростовые куклы, ковролин)
2. `frontend/src/lib/constants.ts` — список SERVICES (карточки услуг на главной)
3. `frontend/src/lib/blogData.ts` — статьи блога
4. `frontend/src/app/vyezd/page.tsx` — страница «Выездная химчистка»
5. `frontend/src/app/mebel/page.tsx` — страница «Химчистка мебели»

## 5. Принципы замены

- Слово «дезинфекция» удаляется или заменяется нейтральным синонимом по контексту:
  - для карточек-преимуществ: «Антибактериальная обработка» (термин уже используется в описаниях, не требует документов);
  - для описаний: «глубокая чистка» / «чистка»;
  - для SEO-ключевых слов и searchVariations: просто удаляются (не заменяются на «дезинфекция-синоним», чтобы не привлекать целевой «дезинфекционный» трафик).
- Меняется только текст; структура данных, ключи, типы остаются без изменений.
- Тексты должны читаться естественно, без «рваных» оборотов.

## 6. Критерии приёмки

1. Поиск «езинфекц» (case-insensitive) по всему репозиторию возвращает 0 совпадений.
2. `npm run lint` — без ошибок.
3. `npx tsc --noEmit` — без ошибок.
4. Тексты описаний читаются естественно, без грамматических/смысловых артефактов.
5. Структура объектов в serviceData.ts/constants.ts/blogData.ts не нарушена (валидный TypeScript, массивы/строки корректны).
6. Длина SEO-полей (seoTitle ≤ ~75 символов, seoDescription ≤ ~160) в разумных пределах.

## 7. Не входит в задачу

- Правки бэкенда (Content Service) — не требуется, контент хранится в frontend.
- Изменения БД, API, миграций, межсервисных контрактов — не требуются.
- Удаление упоминаний «антибактериальная обработка» / «антибактериальные средства» — НЕ требуется (это другой термин, не требует документов).
