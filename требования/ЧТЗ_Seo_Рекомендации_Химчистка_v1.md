## 1. Контекст и исходные данные

### 1.1 Откуда данные
Сайт `da-dryclean.ru` подключён к системе мониторинга (проект `monitoring`).
Коллектор Вебмастера (`collectors/webmaster.py`) дважды в сутки (07:00 и 19:00 МСК)
собирает:
- недельный топ-50 поисковых запросов (`/search-queries/popular`) — показывает, клики, средняя позиция;
- дневную историю каждого запроса (`/search-queries/{query_id}/history`) — клики и показы по дням.

Сбор работает штатно: `monitoring_collector_success{source="webmaster",site="da-dryclean.ru"} = 1`.
В БД на 24.08.2026: **1131 weekly-строка, 3512 daily-строк, 78 уникальных запросов** в окне.

## 2. Ключевые выводы анализа (что не так)

### 2.1 Положительные сигналы
1. **Видимость резко растёт**: показы ×4.5 за 5 дней (250 → 1139, +355%). Яндекс начал показывать сайт по большему числу запросов.
2. **Позиции по ядру вошли в зону 7–8** — это уже нижняя половина 1-й страницы выдачи, близко к ТОП-5.
3. **Тематическое ядро понятно**: матрасы, мягкая мебель, диваны на дому в Москве — это и есть бизнес сайта.
4. Сбор данных работает корректно, без сбоев коллектора.

### 2.2 Проблемы (требуют SEO-работы на стороне сайта)

#### Проблема A — Критично низкий и падающий CTR
CTR упал с **1.60% до 0.61%** при росте показов. Клики выросли с 4 до 7–9 и **застопорились**.
Сниппеты (title/description) не вытягивают клики из выдачи при росте показов.
Это **главный сигнал**: сайт «светится», но на него не кликают.

#### Проблема B — 74% запросов «гибридные» с доменом
Из 50 запросов последнего среза:
- **только латиница (мусорная раскладка): 5 (10%)** — `xbcnrf vt,tkb yf ljve`, `[bvxbcnrf vzurjq vt,tkb yf ljve` и т.п. (пользователи не переключили раскладку). 16 показов, 0 кликов.
- **кириллица + латиница (домен в запросе): 37 (74%)** — `химчистка матраса mos drycleaning`, `химчистка дивана на дому москва mos-drycleaning.ru/furniture/`. Яндекс склеивает текст запроса с URL/брендом → сайт ранжируется по «около-доменным» конструкциям, а не по чистым коммерческим ключам.
- **чистая кириллица: всего 8 (16%)** — и почти все с 1 показом. По «нормальным» SEO-запросам сайт **практически не виден**.

#### Проблема C — Нерелевантная семантика
Сайт ранжируется по нецелевым запросам:
- `как хранить ростовые куклы отзывы` (1 клик, поз. 11)
- `как ухаживать за ростовыми надувными куклами` (поз. 5, 0 кликов — топ, но мусор)
- `диана выезд на дом химчистка матраса` — пользователи ищут **конкурента «Диана»**, а da-dryclean.ru подменяет его
- `услога выездная химчистка салона автомобиля` — другая ниша (автохимчистка)

Это сигнал: поисковик слабо понимает тематику сайта и подставляет его по случайным запросам.

#### Проблема D — Позиция ~9, нужен выход в ТОП-5
Для реального трафика нужно попасть в позиции 1–5 (дают ~70% кликов).
Сейчас средняя позиция 9.02, по ядру 7.5–8.0. Нужен целевой link-building и контент по ядру.

#### Проблема E — Опечаточный потенциал не используется
Заметны запросы с опечатками, по которым сайт уже виден: `химчистка мягкой мебеои`,
`чистка матрасоа`, `химчистка диванв`, `химчистка салона домм`. Это готовый материал
под отдельные посадочные/метатеги, но сейчас он не монетизируется.

## 3. Цели и задачи

### 3.1 Бизнес-цель
Превратить растущую видимость в реальный трафик и заявки: поднять CTR с 0.61% до
минимум 2–3%, вывести ядро (матрасы/мебель/диваны на дому Москва) в ТОП-5 Яндекса,
очистить семантику от мусора.

### 3.2 Пользовательская ценность
По целевым коммерческим запросам вида «химчистка дивана на дому москва» сайт
должен стабильно показываться в ТОП-5 с кликабельным сниппетом (цена, выезд,
гарантия), а не только по околодоменным конструкциям.

### 3.3 Метрики успеха (KPI, измеряемые через мониторинг)

| KPI | Текущее значение | Цель (3 мес) | Цель (6 мес) |
|---|---|---|---|
| Сумма показов в неделю | 1139 | 3000+ | 6000+ |
| Сумма кликов в неделю | 7 | 30+ | 80+ |
| CTR (клики/показы) | 0.61% | ≥ 2.0% | ≥ 3.0% |
| Средняя позиция по ядру | 9.02 | ≤ 7.0 | ≤ 5.0 |
| Доля чистой кириллицы в топе | 16% | ≥ 50% | ≥ 70% |
| Доля мусорной раскладки | 10% | ≤ 2% | 0% |
| Запросов в ТОП-5 Яндекса | ~0 | 5+ | 15+ |
| Нерелевантных запросов в топе | ~5 | ≤ 2 | 0 |

Все KPI автоматически отслеживаются в дашборде `grafana/dashboards/webmaster.json`
проекта мониторинга (после завершения SEO-работ рост будет виден на графике).

## 4. Функциональные требования к сайту (SEO-задачи)

### 4.1 User Stories с Acceptance Criteria

#### US-1: Как пользователь Яндекса, я хочу видеть кликабельный сниппет по «химчистка дивана на дому москва», чтобы перейти на сайт
**Given** сайт ранжируется по запросу «химчистка дивана на дому москва»
**When** Яндекс формирует сниппет
**Then** title содержит коммерческий триггер (цена/выезд/Москва/гарантия)
**And** description содержит УТП и призыв к действию
**And** CTR по этому запросу ≥ 3% в течение 4 недель

#### US-2: Как пользователь, я хочу найти сайт по чистому коммерческому запросу (без домена в запросе)
**Given** пользователь вводит «химчистка матраса на дому»
**When** сайт ранжируется
**Then** сайт виден в ТОП-10 по чистой кириллической форме запроса
**And** доля чистой кириллицы в топ-50 Вебмастера ≥ 50%

#### US-3: Как владелец, я хочу, чтобы сайт не ранжировался по нерелевантным запросам
**Given** в топе Вебмастера присутствуют запросы про ростовых кукол, автохимчистку, конкурента «Диана»
**When** проведена чистка семантики и усилена тематика
**Then** нерелевантных запросов в топ-50 ≤ 2
**And** тематические маркеры (schema.org LocalBusiness) распознаны Яндексом

## 5. Нефункциональные требования

### 5.1 Семантика
- Ядро: «химчистка матраса/матрасов на дому», «химчистка дивана/диванов на дому»,
  «чистка мягкой мебели на дому», «профессиональная химчистка мебели» — все с гео «Москва».
- Минус-слова: «авто», «салон автомобиля», «куклы», «диана» (кроме бренда).
- Опечаточные варианты: отдельные посадочные или мета-блоки под частые опечатки
  (`мебеои`, `матрасоа`, `диванв`, `салона домм`).

### 5.2 Технические требования к сайту
- Микроразметка schema.org **LocalBusiness** с полями: name, areaServed=Москва,
  priceRange, telephone, address, openingHours.
- Микроразметка **Offer** на услугах (цена за услугу).
- Чистые URL без склеивания домена в текст запроса (внутренняя перелинковка по
  ключевым словам, не по доменному имени).
- Хлебные крошки (BreadcrumbList) с тематическими названиями разделов.
- robots.txt + sitemap.xml актуальные, категории услуг индексируемые.

### 5.3 Безопасность и совместимость
- Никаких правок в проекте `monitoring` (это источник данных, не объект оптимизации).
- Все работы — только на стороне сайта `da-dryclean.ru`.
- Сервер сайта и существующее приложение на VPS 130.49.129.241 НЕ затрагивать
  (только контент/разметка/метатеги сайта химчистки).

### 6.1 Структура посадочных страниц (рекомендуемая)
```

/vyezd/                 — выездная химчистка (Москва и область)
```

### 6.2 Мета-шаблон под ядро
- `<title>`: `[Услуга] на дому в Москве — цена от N ₽, выезд за 1 час | da-dryclean`

  часа, безопасная химия, гарантия результата. Цена от N ₽. Звоните!`
- H1: `[Услуга] на дому в Москве`
- В первой 1000 знаков текста: ключ + «Москва» + «на дому» + цена.

### 6.3 Микроразметка (пример)
```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "da-dryclean — химчистка на дому",
  "areaServed": "Москва",
  "priceRange": "₽₽",
  "telephone": "+7-...",
  "address": { "@type": "PostalAddress", "addressLocality": "Москва" },
  "openingHours": "Mo-Su 08:00-22:00"
}
```
На каждой услуге:
```json
{ "@type": "Offer", "priceCurrency": "RUB", "price": "N", "description": "..." }
```

## 7. Декомпозиция на задачи

### TASK-SEO-001: Переработать title/description сниппетов под ядро
**Приоритет:** High (блокирующая, даёт быстрый рост CTR)
**Оценка:** 4 часа
**Зависимости:** —
**Описание:** Переписать `<title>` и `<meta description>` на всех посадочных ядра
(матрасы, мебель, диваны + главная) под коммерческие триггеры: цена, «на дому»,
«Москва», выезд, гарантия. Использовать данные Вебмастера: текст сниппета должен
совпадать с реальными запросами, по которым сайт уже виден (см. §2 — гибридные
запросы показывают, что ядро такое, но домен склеивается).
**Критерии приёмки:**
- [ ] На 5 ключевых посадочных новые title/description с ценой и гео
- [ ] Через 2 недели CTR по ядру в Вебмастере ≥ 1.5%
- [ ] Через 4 недели CTR ≥ 2.0%

### TASK-SEO-002: Усилить релевантность чистых коммерческих запросов
**Приоритет:** High
**Оценка:** 8 часов
**Зависимости:** TASK-SEO-001
**Описание:** Внутренняя перелинковка и тексты по чистым кириллическим ключам
(без домена в тексте). H1, alt, хлебные крошки, первые абзацы текста — по ядру
«химчистка матраса на дому», «химчистка дивана на дому москва» и т.п.
**Критерии приёмки:**
- [ ] Доля чистой кириллицы в топ-50 Вебмастера ≥ 50% за 6 недель
- [ ] По 5 ядрам сайт виден в ТОП-10 по чистой форме запроса

### TASK-SEO-003: Внедрить микроразметку LocalBusiness + Offer
**Приоритет:** High
**Оценка:** 3 часа
**Зависимости:** —
**Описание:** Добавить schema.org LocalBusiness на все страницы, Offer на услуги.
Проверить через Валидатор микроразметки Яндекса.
**Критерии приёмки:**
- [ ] Валидатор Яндекса: 0 ошибок по LocalBusiness
- [ ] Offer есть на 5+ услугах
- [ ] В Вебмастере (раздел «Информация о сайте») отображается бизнес-карточка

### TASK-SEO-004: Очистить семантику от мусора
**Приоритет:** Medium
**Оценка:** 3 часа
**Зависимости:** TASK-SEO-002
**Описание:** Минус-слова в метатегах/robots для страниц, ранкящихся по
нерелевантным запросам (куклы, автохимчистка, «диана»). Усилить тематические
маркеры, чтобы Яндекс перестал подставлять сайт по чужой семантике.
**Критерии приёмки:**
- [ ] Нерелевантных запросов в топ-50 ≤ 2 за 6 недель
- [ ] Запросы про «ростовые куклы» исчезают из топа Вебмастера

### TASK-SEO-005: Использовать опечаточный потенциал
**Приоритет:** Low
**Оценка:** 2 часа
**Зависимости:** TASK-SEO-002
**Описание:** Создать мета-блоки/разделы под частые опечатки (`мебеои`, `матрасоа`,
`диванв`, `салона домм`). Не плодить дорвеи — органично упомянуть в тексте/H2.
**Критерии приёмки:**
- [ ] По 3+ опечаточным вариантам есть видимость в ТОП-10
- [ ] Доля мусорной латинской раскладки в топе ≤ 2%

### TASK-SEO-006: Контентная стратегия по ядру
**Приоритет:** Medium
**Оценка:** 12 часов (несколько статей/кейсов)
**Зависимости:** TASK-SEO-002
**Описание:** Статьи/кейсы по ядру: «как почистить диван от пятен», «химчистка
матраса дома», «уход за мягкой мебелью». Внутренние ссылки на услуги. Цель —
дополнительные точки входа и тематический вес.
**Критерии приёмки:**
- [ ] 5+ статей опубликованы
- [ ] Статьи дают ≥ 10% дополнительных показов через 2 месяца

### TASK-SEO-007: Линкбилдинг для выхода в ТОП-5
**Приоритет:** Medium
**Оценка:** непрерывно (2–3 мес)
**Зависимости:** TASK-SEO-001, TASK-SEO-002
**Описание:** Внешние ссылки с профильных площадок (каталоги услуг Москва,
форумы, обзоры). Цель — поднять позиции ядра с ~7.5 до ≤ 5.0.
**Критерии приёмки:**
- [ ] 5+ ядерных запросов в ТОП-5 через 3 месяца
- [ ] Средняя позиция по ядру ≤ 5.0 через 6 месяцев

### TASK-MON-001: Добавить панель «CTR по ядру» в дашборд Вебмастера
**Приоритет:** Low (удобство отслеживания KPI)
**Оценка:** 1 час
**Зависимости:** —
**Описание:** В проекте `monitoring` добавить в `grafana/dashboards/webmaster.json`
панель CTR = `sum(monitoring_search_clicks_total{site="da-dryclean.ru"}) /
sum(monitoring_search_shows_total{site="da-dryclean.ru"})` — для удобного
отслеживания главного KPI владельцем. **Эта задача выполняется через конвейер
проекта `monitoring`** (не на сайте).
**Критерии приёмки:**
- [ ] Панель CTR отображается в дашборде Вебмастера
- [ ] Проходит pytest/ruff/mypy в проекте monitoring

## 9. Критерии приёмки (проверяемые через мониторинг)

### 9.1 Краткосрочные (4 недели)
- [ ] CTR по da-dryclean.ru ≥ 1.5% (сейчас 0.61%) — `monitoring_search_clicks_total / monitoring_search_shows_total`

- [ ] Доля чистой кириллицы в топе ≥ 30% (сейчас 16%)
- [ ] Микроразметка LocalBusiness валидна (Валидатор Яндекса)

### 9.2 Среднесрочные (3 месяца)
- [ ] Сумма кликов в неделю ≥ 30 (сейчас 7)
- [ ] 5+ ядерных запросов в ТОП-5
- [ ] Доля мусорной раскладки ≤ 2%
- [ ] Нерелевантных запросов в топ-50 ≤ 2

### 9.3 Долгосрочные (6 месяцев)

- [ ] Сумма показов в неделю ≥ 6000
- [ ] Сумма кликов в неделю ≥ 80

### 9.4 Способ проверки
Все KPI видны в Grafana (дашборд «Вебмастер: поиск по сайту», переменная `site=da-dryclean.ru`)
или через прямые запросы к Prometheus:
```promql
# CTR за неделю
sum(monitoring_search_clicks_total{site="da-dryclean.ru"})
  / sum(monitoring_search_shows_total{site="da-dryclean.ru"})

# Средняя позиция по ядру (меньше = лучше)
avg(monitoring_search_position{site="da-dryclean.ru"})

# Динамика кликов по дням
sum by (date) (monitoring_search_daily_clicks{site="da-dryclean.ru"})
```
