# ЧТЗ (упрощённое) — Фикс ссылки «Прайс-лист» в футере (404 на проде)

**Дата:** 2026-08-18
**Маршрут:** Постдеплойный рестарт (Правило 11): Аналитик → Разработчик → Тестировщик → DevOps
**Тип:** малая задача (1 файл, без БД/API/архитектуры)

## 1. Проблема

После прод-деплоя при верификации обнаружено: ссылка «Прайс-лист» в футере
(`href="/api/price-list"`) возвращает **404** на проде.

**Причина:** хост-nginx VPS не содержит `location /api/price-list` из
репозиторного `nginx/prod.conf` (хост-конфиг структурно отличается,
автосинхронизации нет); запрос уходит в catch-all `/api/` → content-service
(FastAPI) → `{"detail":"Not Found"}`. Проблема предсуществующая (с PR #9).

## 2. Решение

Перевести ссылку на статический файл `/price-list.pdf` (public/):
- файл закоммичен (e588519) и уже отдаётся с прода: `200`
- атрибут `download` уже реализован в рендере футера (`<a ... download>`)
  → принудительное скачивание сохраняется (требование коммита 6bab870)
- изменения хост-nginx не требуются (безопасно)

## 3. Файлы для изменения

- `frontend/src/components/Footer.tsx` (строка 22: href → `/price-list.pdf`)

## 4. Критерии приёмки

- AC-1: `grep -r "api/price-list" frontend/src` — пусто
- AC-2: `npm run lint` и `npx tsc --noEmit` — без ошибок
- AC-3: После деплоя: `curl https://da-dryclean.ru/price-list.pdf` → 200
- AC-4: Ссылка в футере ведёт на скачивание PDF (download-атрибут)

## 5. План отката

Один коммит в dev — revert при необходимости. Риск отсутствует.
