# ЧТЗ: Телефоны в Hero в стиле кнопки «Вызвать мастера»

## Задача
Оформить два телефона в Hero (мобильная версия) так же, как кнопку «Вызвать мастера».

## Требования
1. Использовать существующий компонент `Button` (`frontend/src/components/ui/Button.tsx`) с `variant="primary"` и `href="tel:..."` (компонент сам рендерит `<a>`).
2. Телефоны — на всю ширину колонки на мобиле (`w-full`), высота/цвет/шрифт/скругление идентичны кнопке «Вызвать мастера» (bg-accent, h-12, rounded-[28px]).
3. Позиция на мобиле не меняется: после «Оплата по факту», перед формой. На десктопе блок по-прежнему скрыт.
4. Номера из `CONTACTS`, без хардкода.

## Файлы
- `frontend/src/components/Hero.tsx` (единственный)

## Критерии приёмки
- AC1: Телефоны — ссылки `tel:` со стилями primary-кнопки (bg-accent, h-12, rounded-[28px], font-heading).
- AC2: На мобиле порядок сохранён: trust-блок → телефоны → форма.
- AC3: На десктопе блок скрыт.
- AC4: `npm run lint` и `npx tsc --noEmit` — без ошибок; все тесты проходят.
