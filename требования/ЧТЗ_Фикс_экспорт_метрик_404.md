# ЧТЗ: Активация экспорта метрик на проде (404 на /metrics/*)

**Дата:** 2026-08-19
**Маршрут:** 3 (инфраструктурный) — Аналитик → DevOps
**Приоритет:** HIGH (центральный мониторинг не получает данные)

## 1. Проблема

`GET https://da-dryclean.ru/metrics/{tracking,content,node,postgres}` → **404**.
Код экспорта метрик задеплоен (релиз sha-51ae5c5, d569b53), но разовый
`scripts/setup-metrics-export.sh` (nginx-locations в `/etc/nginx/nginx.conf`,
monitoring-key.conf, node_exporter :9100, postgres_exporter :9187) на VPS
не запускался. Кроме того, деплой НЕ синкает этот скрипт (в scp-списке
deploy.yml его нет) и не вызывает его — настройка теряется при пересборке VPS.

## 2. Задачи

- **TASK-INF-001:** Диагностика текущего state VPS (ключ в .env, nginx, экспортеры)
- **TASK-INF-002:** deploy.yml: добавить `scripts/setup-metrics-export.sh` в scp-список
- **TASK-INF-003:** deploy-vps.sh: Step 5.7 — идемпотентный запуск
  setup-metrics-export.sh; ключ: reuse `MONITORING_API_KEY` из .env, иначе
  сгенерировать и сохранить в .env (600)
- **TASK-INF-004:** deploy.yml: post-deploy smoke — `/metrics/tracking` без ключа = 403
- **TASK-INF-005:** Деплой и верификация

## 3. Критерии приёмки

- [AC-1] `GET /metrics/tracking` без ключа → 403 (не 404)
- [AC-2] `POST /metrics/tracking` с ключом → 405
- [AC-3] С ключом `X-Monitoring-Key` все 4 эндпоинта → 200 с ожидаемыми
  метриками (`business_*`, `content_http_*`, `node_cpu_seconds_total`, `pg_*`)
- [AC-4] `MONITORING_API_KEY` хранится в `/opt/app/.env` (chmod 600)
- [AC-5] Post-deploy smoke деплоя включает проверку 403

## 4. Риски

| Риск | Митигация |
|------|-----------|
| Ключа нет нигде → центр. мониторинг не знает новый ключ | Сгенерировать, сохранить в .env; сообщить пользователю как забрать |
| node_exporter download fail на VPS | Скрипт имеет fallback версии; шаг после переключения трафика — сайт не страдает |
| Двойная вставка locations в nginx.conf | Скрипт идемпотентен (grep перед вставкой) |
