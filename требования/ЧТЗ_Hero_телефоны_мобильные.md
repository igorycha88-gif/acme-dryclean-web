# ЧТЗ: Телефоны в Hero на мобильной версии

## Задача
На мобильной версии главной страницы вывести два телефона компании сразу после trust-блока (заканчивается «Оплата по факту»), затем форма (имя, телефон, тип услуги, кнопка «Вызвать мастера»).

## Текущее состояние
- `frontend/src/components/Hero.tsx`: порядок — текст → форма → trust-блок («Оплата по факту» в конце).
- Телефоны: `CONTACTS.phone` (+7 495 226-15-73) и `CONTACTS.phoneAlt` (+7 985 226-15-73) из `frontend/src/lib/constants.ts`.

## Требования
1. Только мобильная версия (`< md`, утилиты `max-md:`). Десктоп — без изменений.
2. Порядок на мобиле: H1 → описание → trust-блок («Оплата по факту») → **2 телефона** → форма → статусы.
3. Телефоны — кликабельные ссылки `tel:` (`CONTACTS.phoneRaw`, `CONTACTS.phoneAltRaw`), крупный читаемый шрифт, белые на тёмном фоне Hero.
4. На десктопе блок телефонов скрыт (`hidden`).
5. Использовать `CONTACTS` из `@/lib/constants`, не хардкодить номера.

## Реализация
- Файл: `frontend/src/components/Hero.tsx` (единственный).
- Обёртка `max-w-3xl` → `max-md:flex max-md:flex-col`, детям — `max-md:order-*` для перестановки; новый блок телефонов `hidden max-md:...`.

## Критерии приёмки
- AC1: На ширине < 768px после «Оплата по факту» идут два телефона, затем поля формы и кнопка.
- AC2: На десктопе вид прежний (форма до trust-блока, телефонов нет).
- AC3: Телефоны кликабельны (`href="tel:+74952261573"`, `href="tel:+79852261573"`).
- AC4: `npm run lint` и `npx tsc --noEmit` — без ошибок.

## Маршрутизация
- Исполнитель: Разработчик → Тестировщик → DevOps.
- Вне скоупа: починка неработающей отправки заявок (нет сервиса на порту 8000) — отдельная задача, сообщено пользователю.
